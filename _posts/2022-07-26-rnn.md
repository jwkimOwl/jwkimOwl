# RNN
## Recurrent Neural Network, RNN
RNN(REcurrent Neural Network) model is a Sequence model that processes input and output in squence. For example of a translator, input sequence will be original sentence which is a sequence of words, and the output sentence will also be a sequence of words. Such models that are for processing sequences are called Sequence models.

## 1. Structure of RNN
Unlike simple artificial neural networks, RNN is not a Feed Forward Neural Network. Feed Forward Neural Network only sends its output value forward, to the output layer. RNN, on the other hand, also sends its result of the activation function to its hidden layer's next calculation.

![RNN_img1.png](/jwkimOwl/assets/img/RNN_img1.png)

Above will give a basic idea about how RNN works. $x_t$ is an input vector from the input layer, and $y_t$ is an output vector. The node where vectors are processed is called a cell, and since it contains a memory of former inputs, it is also called as a memory cell or RNN cell.

RNN cell in the hidden layers uses its own result of the previous step as its input vector. This result of a step that is send to the next step is called a hidden state. In other words, a memory cell at the step t uses the hidden state at the stap t-1 to calculate its hidden state.

![RNN_img2.png](/jwkimOwl/assets/img/RNN_img2.png)

RNN can also be expressed like above, where the cell is drawn, spread out as steps progress.

RNN can have different numbers of input and output vectors, like image below.

![RNN_img3.png](/jwkimOwl/assets/img/RNN_img3.png)

The image shows one-to-many connection, many-to-one connection, and many-to-many connection respectively. Many-to-one connection is often used in classification of a whole sentence, whereas many-to-many can be used in translating a sentence into another sentence.

When input vector is given to a cell, following calculation is done in the hidden layer. Hyperbolic tangent function was used as an activation function to calculate the hidden state of step t, $h_t$. The weight for the input layer is $W_x$, and the weight for the privious step's hidden state is $W_h$. $W_x$ and %W_h$ are constant across all steps.
